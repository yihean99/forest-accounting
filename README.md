# 森系记账本

一个清新森系风格的记账小应用，记录你每天的「小确幸」消费。**纯前端单机版**，零后端、零依赖，数据全部保存在你自己的浏览器本地。双击即用，丢到任意静态托管（GitHub Pages、Vercel、Netlify……）都能跑，还能「添加到主屏幕」像 App 一样使用。

## 功能特性

- **四大记账单元**
  - **吃饭**：早 / 午 / 晚三餐，按天记录明细。
  - **零食**：逐笔记录（名称 + 金额 + 日期）。
  - **想干啥干啥**：逐笔记录（名称 + 金额 + 日期）。
  - **月度杂花预算**：逐笔记录（名称 + 金额 + 日期），设固定月预算。
- **月度预算与剩余**：每个单元一个固定月预算，实时计算本月剩余额度；点「修改数据」可调整本月预算。
- **历史账单**：按月查看四类汇总 + 吃饭每日明细 + 零食 / 想干啥 / 杂花明细。
- **默认数据设置**：修改各单元默认预算（每月 1 号自动恢复该默认值），可选是否同时应用到本月。
- **消费趋势图表**（前端内联 SVG 手写，零外部依赖）
  - 近 7 天每日消费折线图：右侧自适应刻度，悬停 / 点击可查看当天花费。
  - 本月四类消费占比环形图。
- **自动重置**
  - 每日 0 点：清空「今日消费」输入框。
  - 每月 1 号凌晨 4:00：归档上月账单、恢复默认预算、其余清零。
- **本地持久化**：数据保存在浏览器 `localStorage`，关闭页面、重启电脑都不丢。
- **备份 / 恢复**：一键导出 JSON 备份（下载文件或复制内容），支持文件导入 / 粘贴导入，方便跨设备迁移数据。
- **输入校验**：所有金额输入框不允许负数。
- **PWA**：可「添加到主屏幕」，离线也能用。

## 技术栈

- **前端**：原生 HTML / CSS / JavaScript，零框架、零外部 CDN、零构建工具。
- **单文件**：所有 HTML / CSS / JS 内联在根目录的 `index.html` 一个文件里；图标与图表均为手写内联 SVG。
- **数据**：浏览器 `localStorage`，无需任何服务器。
- **后端**：**无**。

## 快速开始

### 方式一：直接双击打开（最简单）

下载或 clone 本项目，双击根目录下的 `index.html` 即可开始记账。

### 方式二：本地起个静态服务（推荐，PWA / 图标更完整）

```bash
cd forest-accounting
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

### 方式三：部署到静态托管

把项目根目录整个上传到 GitHub Pages / Vercel / Netlify / 任意静态空间即可，无需任何构建步骤。

## 数据说明

- 所有账本数据保存在**浏览器本地**（`localStorage`），不会上传到任何服务器。
- 数据与「浏览器 + 站点地址」绑定，以下情况会导致数据不可见或丢失，请注意：
  - 清理浏览器缓存 / 站点数据；
  - 更换浏览器或设备；
  - 使用隐私 / 无痕模式；
  - 更换部署域名或访问路径。
- 建议定期通过「备份 / 恢复」导出 JSON 备份保存，或复制备份内容在设备间迁移，避免数据丢失。
