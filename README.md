# 森系记账本

一个清新森系风格的记账小应用，记录你每天的「小确幸」消费。**纯前端单机版**，零后端、零依赖，数据全部保存在你自己的浏览器本地。双击即用，丢到任意静态托管（GitHub Pages、Vercel、Netlify……）都能跑，还能「添加到主屏幕」像 App 一样使用。

##  功能特性

- **四大记账单元**
  -  **吃饭**：早 / 午 / 晚 三餐，按天记录明细。
  -  **零食**：逐笔记录（名称 + 金额 + 日期），本月累计。
  -  **想干啥干啥**：逐笔记录（名称 + 金额 + 日期）。
  -  **杂花**：洗澡 / 水费 / 洗衣机。
- **月度预算与剩余**：实时计算本月剩余额度。
- **历史账单**：按月查看四类汇总 + 吃饭每日明细 + 零食 / 想干啥 / 杂花明细。
- **默认数据设置**：随时修改默认预算，可选是否同时改本月。
- **消费趋势图表**（前端内联 SVG 手写，零外部依赖）
  - 近 30 天每日消费折线图。
  - 本月四类消费占比环形图。
- **自动重置**
  - 每日 0 点：清空「今日消费」输入框。
  - 每月 1 号凌晨 4:00：归档上月账单、恢复默认预算、其余清零。
- **本地持久化**：数据保存在浏览器 `localStorage`，关闭页面、重启电脑都不丢。
- **PWA**：可「添加到主屏幕」，离线也能用。
- **一键清空**：页面右上角「清空数据」可抹除本机全部账本（不可恢复，操作前会二次确认）。

##  技术栈

- **前端**：原生 HTML / CSS / JavaScript，零框架、零外部 CDN、零构建工具。
- **单文件**：所有 HTML / CSS / JS 内联在 `static/index.html` 一个文件里。
- **数据**：浏览器 `localStorage`，无需任何服务器。
- **后端**：**无**。

##  快速开始

### 方式一：直接双击打开（最简单）

下载或 clone 本项目，双击 `static/index.html` 即可开始记账。

### 方式二：本地起个静态服务（推荐，PWA / 图标更完整）

```bash
cd forest-accounting/static
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

### 方式三：部署到静态托管

把 `static/` 目录整个上传到 GitHub Pages / Vercel / Netlify / 任意静态空间即可，无需任何构建步骤。

##  数据说明

- 所有账本数据保存在**浏览器本地**（`localStorage`），不会上传到任何服务器。
- 数据与「浏览器 + 站点地址」绑定，以下情况会导致数据不可见或丢失，请注意：
  - 清理浏览器缓存 / 站点数据；
  - 更换浏览器或设备；
  - 使用隐私 / 无痕模式；
  - 更换部署域名或访问路径。
- 建议定期使用浏览器开发者工具自行导出 `localStorage` 备份，或后续按需扩展「导入 / 导出 JSON」功能。
