# 森系记账本 🌿

一个清新森系风格的记账小应用，记录你每天的「小确幸」消费。支持多账号、云端同步（自带后端 + 本地 JSON 数据库），手机电脑都能用，还能添加到主屏幕像 App 一样用。

## ✨ 功能特性

- **账号密码登录 / 注册**：注册时可设置本月默认预算（吃饭 / 零食 / 想干啥 / 杂花）。
- **四大记账单元**
  - 🍚 **吃饭**：早 / 午 / 晚 三餐，按天记录明细。
  - 🍬 **零食**：逐笔记录（名称 + 金额 + 日期），本月累计。
  - 🎯 **想干啥干啥**：逐笔记录（名称 + 金额 + 日期）。
  - 🧺 **杂花**：洗澡 / 水费 / 洗衣机。
- **月度预算与剩余**：实时计算本月剩余额度。
- **历史账单**：按月查看四类汇总 + 吃饭每日明细 + 零食 / 想干啥 / 杂花明细。
- **默认数据设置**：随时修改默认预算，可选是否同时改本月。
- **消费趋势图表**（前端内联 SVG 手写，零外部依赖）
  - 近 30 天每日消费折线图。
  - 本月四类消费占比环形图。
- **自动重置**
  - 每日 0 点：清空「今日消费」输入框。
  - 每月 1 号凌晨 4:00：归档上月账单、恢复默认预算、其余清零。
- **PWA**：可「添加到主屏幕」，离线也能用。
- **双模式**：前端优先连后端 API；连不上时自动降级为「本地模式」（数据存浏览器），不丢功能。

## 🛠 技术栈

- **后端**：Python + FastAPI，数据持久化为服务器本地 JSON 文件（`data/` 目录），账号之间数据隔离。
- **前端**：原生 HTML / CSS / JavaScript，零框架、零外部 CDN，单页内联所有资源。
- **部署**：任意支持 Python 的服务即可（已适配平台注入的 `PORT` 环境变量）。

## 🚀 本地运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动（默认 8000 端口，可用 PORT 环境变量覆盖）
python server.py

# 3. 浏览器打开
#    http://localhost:8000/       会自动跳转到登录页
#    http://localhost:8000/static/login.html
```

注册一个账号即可开始记账。数据保存在运行目录下的 `data/` 文件夹里（已被 .gitignore 忽略，不会提交到仓库）。

## 📦 目录结构

```
forest-accounting/
├── server.py            # FastAPI 后端：注册/登录/数据读写 + 托管前端
├── requirements.txt     # Python 依赖
├── static/              # 前端静态资源
│   ├── login.html       # 登录 / 注册页
│   ├── accounting.html  # 记账主页（核心逻辑 + 图表）
│   ├── manifest.json    # PWA 配置
│   ├── sw.js            # Service Worker（离线缓存）
│   ├── icon-192.png     # 应用图标
│   └── favicon.png      # 站点图标
└── data/               # 运行时自动生成（用户数据，已在 .gitignore 忽略）
```

## 📝 接口一览（后端）

| 方法   | 路径              | 说明                         |
| ---- | --------------- | -------------------------- |
| POST | `/api/register` | 注册账号（可携带默认预算）              |
| POST | `/api/login`    | 登录，返回 token                |
| GET  | `/api/health`   | 健康检查（前端判断是否连上后端）           |
| GET  | `/api/data`     | 读取当前用户数据（需 `X-Auth-Token`） |
| PUT  | `/api/data`     | 写入当前用户数据（需 `X-Auth-Token`） |

## ⚠️ 说明

本项目为个人记账工具，自带后端使用本地 JSON 文件存储，**适合自部署 / 个人使用**。若需更高并发或更强的数据安全，可将 `server.py` 中的数据层替换为真正的数据库（如 PostgreSQL）。
